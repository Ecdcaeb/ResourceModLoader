## 资源模载器

这个模组把资源包作为 Forge 模组加载，并扩展资源包能做的事。

- [模块](https://ecdcaeb.github.io/ResourceModLoader/zh_cn/modules) — 资源模组文件格式。
- [Java](https://ecdcaeb.github.io/ResourceModLoader/zh_cn/java) — 给 Java Minecraft 模组用的 API。
- [RML 2.0 计划](2_RML_2.0_Plan.md) — Agent Native 内容运行时、架构重建与分阶段验收。

在这篇文档里，`/` 表示 `assets/<domain>/`。
