### `rml:config_define`

Default path: `/config/define`

Define a Forge `.cfg` from a cfg file. Names match: `example.cfg` → `example.cfg`.

Example:

```editorconfig
# Configuration file

##########################################################################################################
# entityelectricshakingconf
#--------------------------------------------------------------------------------------------------------#
# ap.configMisc.desc
##########################################################################################################

entityelectricshakingconf {
# ap.config.maxCountIs1.desc
B:ap_maxIs1_desc=true
}
```
