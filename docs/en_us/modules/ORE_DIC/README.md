### `rml:ore_dic`

Default path: `/ore_dic/`

Format: an array of [TagOre](https://ecdcaeb.github.io/ResourceModLoader/en_us/deserializer/TagOre).

Example:

```json
[
  {
    "ore": "oreDiamond",
    "item": {
      "item": "minecraft:dirt",
      "count": 1,
      "data": 0
    }
  }
]
```
